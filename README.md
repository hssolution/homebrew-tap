# HS Solution Homebrew Tap

Official Homebrew casks for apps made by HS Solution.

## DubbingMate

Dub YouTube videos by reading subtitles aloud with on-device TTS — <https://dubbingmate.com/>

```sh
brew install --cask hssolution/tap/dubbingmate
```

The app is signed with an Apple Developer ID and notarized. It updates itself after install.

## RDPyon

RDPyon — RDP server for Mac (connect from Windows Remote Desktop) — <https://rdpyon.com/>

```sh
brew install --cask hssolution/tap/rdpyon
```

## Notes

- Casks point only to the official download files on dubbingmate.com and rdpyon.com.
- Issues: open one in this repository or write to support@dubbingmate.com.
